# HR Recruitment Agent System

## Overview
This project is an end-to-end AI-powered HR recruitment pipeline built using LangGraph.

## Features
- ATS Resume Scoring
- Technical Interview Agent
- HR Screening Agent
- Interview Scheduling
- HR Dashboard
- HR Chatbot

## Tech Stack
- Python
- LangGraph
- Pandas (for database simulation)

## Architecture
Pipeline:
Resume → ATS → Interview → HR Screening → Scheduling

## Memory
- Short-Term Memory: LangGraph State
- Long-Term Memory: Pandas DataFrame
